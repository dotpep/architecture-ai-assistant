If you're new to any of these technologies, here's what to study:

### Essential (1-2 weeks)
1. NestJS basics (TypeScript, decorators, modules)
2. React fundamentals (components, hooks, state)

## ⚠️ Common Mistakes to Avoid

1. **Scope Creep**: Focus on MVP first, add features later
   - Solution: Strict feature prioritization

2. **Over-Engineering**: Don't build for 1M users on day 1
   - Solution: Ship MVP, optimize when needed

3. **Ignoring Users**: Don't assume what users want
   - Solution: Ship early, get feedback, iterate

4. **Poor AI Quality**: Bad prompts = bad outputs
   - Solution: Invest heavily in prompt engineering

5. **Weak Community**: Don't rely only on ads
   - Solution: Build organic community early

6. **Premature Scaling**: Don't hire fast before PMF
   - Solution: Stay lean, grow methodically

7. **Ignoring Competitors**: Don't dismiss existing tools
   - Solution: Differentiate clearly, solve real problems

8. **No Documentation**: Don't skip writing docs
   - Solution: Document as you build
